# Club Store

Landing page de uma loja de produtos tecnológicos, desenvolvida para praticar desenvolvimento web, estilização e interações.

## Tecnologias

HTML5, CSS3, JavaScript, Google Fonts, SVG

## Funcionalidades

Carrossel de produtos, navegação entre produtos, animações CSS e indicadores de produto.

## Objetivo

Projeto desenvolvido durante meus estudos em Análise e Desenvolvimento de Sistemas para praticar conceitos de desenvolvimento front-end.
